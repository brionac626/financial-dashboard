# 前端架構與驗收規格

## 架構

Astro 輸出靜態 HTML，單一 `Dashboard` React island 使用 `client:load` 啟動。沿用 OnePageTemplate 的目錄分層、Strict TypeScript 與 `@/*` 路徑別名；移除展示模板的旅遊內容、模擬提交及無關 SEO 設定。原模板未修改。

瀏覽器選檔 → 逐檔 Worker 解析 → `ImportResult` 預覽 → 選取有效檔案 → 以年月合併 → React 狀態 → localStorage 保存。沒有後端介面。

## 資料契約

- `AccountBalance`：原始列識別、分類、帳戶、功能、目標與數值金額。
- `MonthlySnapshot`：年月、來源檔名及帳戶列表。每個年月唯一。
- `InsuranceSnapshot`：獨立識別、來源檔名、匯入時間、保單列表；每筆保單包含類別、區段、險種與原始欄位。
- `ImportResult`：候選月份、選用保險快照、錯誤與說明。檔案發生結構／數值錯誤時整檔拒絕；批次中其他檔案不受影響。
- `StoredData`：版本 1、月份、保險快照與顯示偏好。讀取時檢查巢狀型別、月份唯一性、分類與有限數值。未知版本視為不可讀，不自動遷移或覆寫。

財務摘要由明細即時計算，不保存衍生總額。缺漏月份產生 `null` 趨勢點，避免暗示不存在的觀測值。保險沒有年份／月份趨勢，亦無年化保費。

## UI 與可用性

繁體中文、TWD、淺色綠系儀表板。三個檢視為財務總覽、帳戶明細與保險概況。月份選擇套用財務資料；保險選擇以來源為準。

原生 dialog 提供焦點限制、Escape 關閉與焦點返回。所有主要操作使用 button/select，圖表另有可讀資料表或分類數值，錯誤使用 alert、操作進度使用 live region。手機表格僅在容器內水平捲動，金額不用顏色作為唯一資訊。

## 邊界與保護

檔案不送到網路。SheetJS 在 Worker 執行，輸入大小、工作表範圍及解析時間有上限。數字不明確時指出儲存格並拒絕，不把錯誤當零。原始公式不執行。

損壞儲存不直接覆寫；保存失敗保留記憶體狀態並提示。刪除操作須確認，只刪除程式自己的儲存鍵；刪除失敗不顯示成功。

## 驗證

`npm test` 驗證原始範本、現金計算、空值及零值、負值、公式快取、無效表頭與分類、保險空列、原始保費、重複年月、跨年排序、斷點、部分失敗、儲存損壞／配額及清除隔離。

`npm run build` 包含 Astro / TypeScript 檢查與正式靜態建置。瀏覽器檢查包括空狀態、匯入預覽、有效資料、月份／保險切換、重新整理、清除確認、桌面與手機版面、鍵盤操作與網路請求。
